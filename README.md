# 排序算法可视化演示

一个交互式的排序算法可视化工具，帮助直观理解6种经典排序算法的工作原理。

## 支持的算法

| 算法 | 时间复杂度 | 特点 |
|------|-----------|------|
| 冒泡排序 | O(n²) | 实现简单，相邻元素两两比较 |
| 选择排序 | O(n²) | 每轮选最小值，交换次数少 |
| 插入排序 | O(n²) | 类似整理扑克牌，对近乎有序数据极快 |
| 快速排序 | 平均O(n log n) | 分治思想，通用排序最快 |
| 归并排序 | O(n log n) | 稳定排序，需额外空间 |
| 堆排序 | O(n log n) | 原地排序，空间开销低 |

## 功能特性

- 实时动画演示排序过程
- 调节数组大小（5~100个元素）
- 调节排序速度（慢/中/快）
- 实时统计比较次数和交换次数
- 支持暂停/继续/重置操作

## 颜色含义

- **黄色**：正在比较的元素
- **红色**：正在交换的元素
- **绿色**：已排序完成
- **紫色**：基准值/当前最小值

## 使用方法

直接用浏览器打开 `sort-visualizer.html` 即可运行，无需安装任何依赖。

## 技术栈

- 纯 HTML + CSS + JavaScript
- Tailwind CSS（CDN引入）
- 无后端依赖，单文件运行
